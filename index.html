Modified Insertion Sort Lab – Odd Indices Only

Student coding lab · Python + optional Judge0 CE run

Problem

Goal: Implement a routine that treats the input as a 0-based array.
  • Odd indices are 1, 3, 5, …
  • Even indices are 0, 2, 4, …
  • You must sort only the values at odd indices.
  • Values at even indices must remain unchanged (same index, same value).

Illustration (no arrays shown)

Picture the array as alternating “even slots” and “odd slots.” Only the values sitting in odd slots should end up sorted among themselves; each even slot keeps the same value in the same place.

Constraints

  • Use Python 3. Implement def sort_odd_indices_only(arr): that returns a list.
  • Return a new list; do not mutate the argument passed in.
  • You may keep an if __name__ == "__main__": block for your own prints; tests run after it.
  • Straightforward O(n²)-style solutions are fine for lab-sized inputs.
  • A few sample tests are shown below; additional hidden tests are run on Judge0.
